# Carousel: parallax

```js
import { createParallax } from '@shelamkoff/carousel'
const plugin = createParallax({ factor: 0.2 })
```

Оборачивает содержимое в parallax layers и использует числовые кадры ядра `render` при переходах и drag. Собственного цикла анимации и разбора CSS transform больше нет. `factor` ограничивается диапазоном `0..1`. Атомарное перемещение сохраняет состояние при наличии поддержки; удаление плагина восстанавливает структуру. Уменьшение движения отключает смещение.

Ленивое содержимое синхронизируется через уведомление ядра об отрисовке. При пересборке обёртки обновляются без собственного таймера или опроса в покое.
