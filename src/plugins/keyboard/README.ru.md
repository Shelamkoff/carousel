# Carousel: клавиатура

```js
import { createKeyboard } from '@shelamkoff/carousel'
const plugin = createKeyboard({ scope: 'container' })
```

Обрабатывает Left/Right горизонтально, Up/Down вертикально, Home и End в обеих ориентациях. Поля ввода и редакторы сохраняют свои клавиши. Scope `container` изолирует экземпляры; `document` включается явно и реагирует только на подходящий фокус. Вложенная карусель владеет своими событиями: её необработанные клавиши не переключают внешнюю.

Уже обработанные события, ввод через IME и сочетания с Alt/Ctrl/Meta сохраняют своё поведение. Обработчик использует документ карусели, в том числе при размещении внутри iframe того же источника.
