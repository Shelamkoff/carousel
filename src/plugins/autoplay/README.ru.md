# Carousel: autoplay

```js
import { createAutoplay, createControls } from '@shelamkoff/carousel'
const autoplay = createAutoplay({
  interval: 3000,
  pauseOnHover: true,
  pauseOnFocus: true,
  pauseOnInteraction: true,
})
const controls = createControls({ playPause: true, progress: 'circle', counter: true })
// Оба плагина передаются в plugins; порядок установки не важен.
```

Запускается после установки, если есть следующая позиция. Первый переход начинается через `interval`; последующие интервалы отсчитываются после завершения перехода. Одни часы используются для навигации и `getState()`, отдельного таймера прогресса нет.

| Опция | По умолчанию | Поведение |
| --- | --- | --- |
| `interval` | `3000` | Время показа в миллисекундах, без длительности перехода. Число больше нуля и не больше `2147483647` — предела нативного таймера. |
| `pauseOnHover` | `true` | Приостанавливать показ при наведении. |
| `pauseOnFocus` | `true` | Приостанавливать показ при фокусе на слайдах или элементах управления. |
| `pauseOnInteraction` | `true` | Остановить показ после ручной навигации или взаимодействия указателем. `false` разрешает продолжение после жеста и перехода. |

Скрытая вкладка всегда приостанавливает показ. При нескольких активных указателях продолжение ждёт освобождения всех. Наведение, фокус, скрытая вкладка и `stop()` сохраняют оставшееся время; `start()` продолжает его. Явный Play разрешает продолжение под текущим курсором/фокусом кнопки до следующего входа или переноса фокуса. Скрытая вкладка и удерживаемые указатели этому исключению не подчиняются.

Новый слайд получает полный интервал после перехода. Простое изменение размеров сохраняет время. Изменение выбранного слайда, количества слайдов или отмена перехода запускает свежий интервал. На последней конечной странице, при пустой/одиночной коллекции или шаге loop, который не меняет слайд, показ останавливается. Play в таком состоянии отключён; нужно сначала перейти назад либо изменить коллекцию.

Методы: `start()`, `stop()`, `toggle()`, `isActive()`, `getState()`. `isActive()` отражает запрошенное воспроизведение и может быть `true` при временной паузе от наведения. Снимок состояния — `{ available, active, paused, running, interval, remaining, progress }`: `remaining` в миллисекундах, `progress` — прошедшая доля `0..1`, `running` означает активный отсчёт. Во время перехода `paused` также равен `true`.

`autoplay:state` вызывается при изменении состояния, а не на каждом кадре. `autoplay:start` / `autoplay:stop` по-прежнему не имеют данных. [Controls](../controls/README.ru.md) добавляет кнопку, прогресс и счётчик; автопоказ сам не создаёт UI.
